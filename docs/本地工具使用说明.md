# 市场观察 本地工作台

## 打开工具

完整解压发布包，双击 `MarketWorkbench.exe`。工具自动打开 `http://127.0.0.1:8765`。启动窗口保持打开，关闭窗口即停止本地服务。若服务已经运行，再次双击会打开现有工作台。

普通使用无需 Python、Node、Agent、MCP 或模型 API。采集需要联网、Chrome 和能访问对应市场榜单的生意参谋账号。

## 首次连接

1. Chrome 打开 `chrome://extensions`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择发布包中的 `extension/unpacked`。这一层直接包含 `manifest.json`，不要进入 `icons`。
3. 如果已有旧版取数桥，先停用旧版，避免多个扩展抢任务。本版为 0.9.0。
4. 在同一个 Chrome 登录生意参谋，打开“市场 → 市场排行 → 商品”。选择类目、统计周期、榜单、店铺类型、价格带和关键词。
5. 刷新榜单页面并翻页一次，回到工具点击“识别榜单”。

扩展由哪个文件夹加载，就保留那个文件夹。程序目录移动后需要重新加载扩展。升级扩展文件后，在扩展卡片点击刷新，再刷新生意参谋页面。

## 采集与导出

- 首版从生意参谋当前页面同步条件，不在本地构造未验证的筛选参数。修改条件后重新识别；若识别到多组条件，可在“榜单来源”选择。
- 点击“开始采集”，读取该条件下账号可访问的全部页。保持原榜单标签页打开，不退出、不切换账号。
- 可随时停止。当前请求结束后停止，已完成部分保留。账号或浏览器实例变化会使本次数据作废。
- 商品表支持搜索、分页和商品链接。搜索只影响预览，Excel 始终导出该任务全部已采集记录。
- 任务结束且有数据后点击“导出 Excel”。工作簿包含商品榜单和采集说明，未完成任务会明确标注。
- 图片按链接导出，不内嵌图片。数值区间保留原文，不推算精确销量；缺失字段留空。
- 任务和结果保存在 `%LOCALAPPDATA%/SycmMarket/market.db`，重新打开仍可从采集记录导出。

## 常见情况

- “清单文件缺失”：选错目录，请选直接包含 `manifest.json` 的目录。
- “浏览器已连接但没有榜单”：确认正在市场商品页，刷新并翻页；本店“商品排行”不是市场榜。
- 登录过期、权限不足或平台要求验证：程序停止，在平台完成处理后重新识别并重新采集。
- 重复页或数量不足：保留部分数据并说明原因，不会显示为完整成功。
- 端口 8765 被其他软件占用：关闭占用程序，或开发者通过 `MARKET_PORT` 指定其他端口。

## 开发

Python 3.10+、Node 20.19+。安装 `requirements-test.txt`，前端运行 `npm ci` 和 `npm run build`。双击 `scripts/start_market.cmd` 或执行 `python run_market.py`。

测试：`python -m pytest tests_web -q`；`npm --prefix frontend test`。启动服务后在 frontend 执行 `npx playwright test`。浏览器测试使用独立测试会话，不复用真实账号。

打包：运行 `scripts/build_market.ps1`，产物位于 `dist/MarketWorkbench`。本地文件、浏览器登录状态、运行数据库和 HAR 不要提交 Git。
