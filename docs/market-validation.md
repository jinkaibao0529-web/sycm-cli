## 真实链路

- 通过本仓库 0.9.0 扩展，从用户已登录的市场商品页识别 `/mc/mq/mkt/item/offline/rank.json`，不使用电脑操作工具。
- 验证范围为免费市场版、近 7 天、交易总量榜的一个类目。总数 300，每页 10，30 页采集完成，去重后 300 件，首末排名为 1 和 300。
- 适配真实返回的 `cateRankId`、`coreKeyWord`、`item`、`shop`、`payByrCnt` 和 `uv`。11 列均可映射。部分行未返回变化值或关键词，按空值保留。
- Excel 包含商品榜单和采集说明，300 条商品。长 ID 使用文本类型，区间保留中文原文，图片与商品均以链接保存。
- 独立发布包启动、连接检查和工作进程取数已验证。另一次发布包任务在 3 页 / 30 件后取消，部分 Excel 的状态说明与行数已核对；该测试任务在验证后清理，不影响完整任务。
- 从发布包提供的真实网站通过导出按钮触发浏览器下载，成功保存完整 Excel。

## 自动检查

- 11 项 pytest：真实字段形状、缺失值、区间、去重、账号变化作废、重复页停止、取消、重启恢复、来源/会话保护、文本类型导出及 Windows ASCII IPC。
- 4 项 Node 扩展测试：排除本店榜单、只读约束、敏感参数不外传、固定筛选条件分页和零基页码。
- 2 项 Playwright：实际服务桌面/390px 窄屏无页面横向溢出、导航、弹窗、减少动态效果；隔离模拟数据下的采集、搜索、分页和取消接口契约。
- TypeScript 和 Vite 构建通过，上游 CLI 帮助入口可用。
- impeccable 机械检测无发现。独立完成评审提出的三项修改：辅助文字对比度、表格/连接状态退出过渡、移动导航可访问名称，复核均为 resolved / ship。设计系统已写入 DESIGN.md 和 .impeccable/design.json。

## 明确边界

其他类目、日期类型、榜单、价格带、关键词组合和账号版本尚未逐一验证。观察器只接受实际页面出现的只读市场商品排行请求；不支持的响应结构、加密数据或 POST 接口会保持未识别，不猜测成功。当前条件在生意参谋设置，本地识别后按固定条件采集。并发只允许一个任务，首版不提供自动定时或断点续采。

真实结果、运行数据库、会话标识和截图仅保存在本机，不随源码发布。
